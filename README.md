# 📱 Mobile Sales Data Analysis using SQL

## 📌 Project Overview
This project analyzes mobile sales data using SQL to extract meaningful insights related to revenue, product performance, and customer demand. It demonstrates the use of SQL for data analysis and business decision-making.


## 🎯 Objectives
- Calculate total revenue and sales performance  
- Identify top-selling brands and products  
- Analyze regional sales distribution  
- Understand customer preferences based on product specifications  


## 🛠️ Tools & Technologies
- MySQL  
- SQL (Structured Query Language)  


## 📊 Dataset Description
The dataset contains mobile sales information with the following key fields:
- Product  
- Brand  
- Price  
- Quantity_Sold  
- Region  
- RAM / ROM / Processor details  
- Customer information  


## 🧹 Data Preparation
- Created database and table structure  
- Imported dataset using `LOAD DATA INFILE`  
- Ensured proper data formatting for analysis  


## 📈 Key Analysis Performed

### 🔹 Total Revenue
- Calculated overall revenue using price and quantity sold  

### 🔹 Top Selling Brands
- Identified brands with highest sales volume  

### 🔹 Top Products by Revenue
- Ranked products based on total revenue generated  

### 🔹 Regional Sales Analysis
- Compared revenue across different regions  

### 🔹 Product Specification Analysis
- Analyzed demand based on specifications like RAM  


## 🔍 Key Insights
- Certain brands dominate in terms of total sales  
- Revenue is concentrated in specific regions  
- Customer demand varies based on product specifications  
- High RAM configurations show strong sales trends  


## ✅ Conclusion
This project highlights how SQL can be effectively used to analyze structured data and generate actionable business insights.
